# 🚗 Root Cause Analysis of Vehicle CO2 Emissions Using Power BI

## 📌 Overview

This project presents an analytical report on vehicle CO2 emissions using Power BI. The objective is to identify key factors contributing to emissions and uncover patterns through AI-driven visualizations.

---

## 💼 Business Scenario

Environmental sustainability is a growing global concern, with vehicle CO2 emissions being a major contributor to air pollution. Organizations and policymakers require data-driven insights to understand emission drivers and support decisions that reduce environmental impact.

This report analyzes vehicle data to identify the key factors influencing CO2 emissions and highlights opportunities to promote low-emission technologies such as hybrid and electric vehicles.

---

## 🎯 Objectives

* Identify key drivers of CO2 emissions
* Perform root cause analysis using AI visuals
* Analyze relationships between engine size and emissions
* Detect high and low emission segments
* Enable interactive data exploration

---

## 🛠 Tools & Technologies

* Power BI
* Data Modeling
* DAX (basic measures)
* AI Visualizations (Key Influencers, Decomposition Tree)

---

## 📊 Report Components

* KPI Card (Vehicles analyzed)
* Key Influencers Analysis
* Top Segments Analysis
* Scatter Plot (Engine Size vs CO2 Emissions)
* Decomposition Tree (AI-driven root cause analysis)

## 🔍 Key Insights

* Internal Combustion Engine (ICE) vehicles produce the highest CO2 emissions
* Larger engine sizes are strongly associated with higher emissions
* Petrol vehicles emit more CO2 compared to alternative fuel types
* Electric and hybrid vehicles show significantly lower emissions
* Lowest emissions (~119 g/km) are observed in HEV vehicles with small engines and manual transmission

---

## 📈 Business Impact

The analysis highlights the importance of transitioning to hybrid and electric vehicles to reduce environmental impact. It also demonstrates how engine size and vehicle configuration influence emissions, supporting data-driven decision-making.
